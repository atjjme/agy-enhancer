================================================================================
                      AGY Enhancer (Antigravity 增强器) 使用说明
================================================================================

欢迎使用 AGY Enhancer！
本项目专为 Google Antigravity (AGY) 桌面客户端打造，提供沉浸式全屏、居中主输入框、
多标签页支持、快捷折叠、右键扩展以及全功能 Web 可视化设置面板。

--------------------------------------------------------------------------------
一、 极简推荐上手（99% 用户只需此两步）
--------------------------------------------------------------------------------

1. 【首次安装 / 启动】：
   直接双击根目录下的【 install.bat 】
   - 自动检测 Node.js 运行环境；
   - 自动注入增强补丁并无感配置后台自启；
   - 自动在浏览器弹出设置面板。

2. 【日常调参 / 随时修改配置】：
   随时双击根目录下的【 settings.html 】
   - 会直接在浏览器中打开配置面板；
   - 界面右上角显示绿色指示灯（● 服务已连接）即表示配置即时生效；
   - 任何修改实时热生效，无需重启客户端。


--------------------------------------------------------------------------------
二、 根目录核心文件用途
--------------------------------------------------------------------------------

- install.bat        : 一键安装与开机自启部署脚本（初次使用双击它即可）。
- settings.html      : 可视化 Web 设置仪表盘，支持随时双击直接配置所有功能。
- 使用说明.txt       : 本文本说明文件，介绍各文件用途与进阶手动操作。
- README.md          : 英文版项目完整技术文档（GitHub 仓库主页展示）。
- docs/              : 详细文档目录（包含 docs/README.zh-CN.md 简体中文完整手册）。
- scripts/           : 所有底层执行脚本、服务进程与控制工具目录。
- src/               : 增强器核心 JavaScript 源码。


--------------------------------------------------------------------------------
三、 scripts 目录下所有程序与脚本详解（手动运行指引）
--------------------------------------------------------------------------------

如果你希望更精细地控制增强器的各个环节，可以直接进入 scripts 目录手动执行对应程序：

1. 【静默启动服务】 start-service-silent.vbs
   - 推荐指数：★★★★★
   - 用途：在后台彻底静默启动 loader 守护进程，完全没有任何黑框或命令行弹窗。
   - 适用场景：手动关闭服务后，想要无声无息地重新开启后台注入与配置监听服务。

2. 【停止服务】 stop-service.bat
   - 推荐指数：★★★★★
   - 用途：安全停止当前正在运行的所有增强器后台服务（包括释放 37210 本地端口）。
   - 适用场景：想临时关闭增强器，或者在重新安装/更新前清理旧进程。

3. 【唤起设置面板】 settings.bat
   - 推荐指数：★★★★☆
   - 用途：确保后台服务就绪，并自动在默认浏览器中打开 settings.html。
   - 提示：直接双击根目录的 settings.html 具有完全相同的效果。

4. 【前台调试启动】 start-enhancer.bat
   - 推荐指数：★★★☆☆
   - 用途：以“可见命令行黑框”形式启动增强服务。
   - 适用场景：排查问题或开发者调试。窗口中会实时滚动打印 CDP 注入日志、端口状态与
     报错详情。关闭该命令行黑框即终止服务。

5. 【单设开机自启】 setup-autostart.bat
   - 推荐指数：★★☆☆☆
   - 用途：仅为当前 Windows 用户创建开机自启动快捷方式（指向后台静默启动脚本）。
   - 适用场景：之前取消了自启，现在想单独重新添加开机自启，而无需重新安装。

6. 【移除开机自启】 remove-autostart.bat
   - 推荐指数：★★☆☆☆
   - 用途：安全清理 Windows Startup（启动文件夹）中的自启项，开机不再自动启动增强器。
   - 适用场景：只想在需要时手动运行增强器，不想让它随 Windows 开机启动。

7. 【完整卸载清理】 uninstall.bat
   - 推荐指数：★★★★☆
   - 用途：彻底卸载增强器！自动终止后台进程、移除开机自启项、清除客户端注入补丁，
     使 Antigravity 恢复官方原始干净状态。

8. 【核心守护引擎】 loader.js
   - 用途：底层的 Node.js 核心脚本（由上述各 .bat/.vbs 自动调用）。
   - 功能：监听本地 127.0.0.1:37210 端口提供设置 API，并通过 CDP 自动探测和热注入
     Antigravity 客户端页面。

9. 【独立设置服务】 settings-server.js
   - 用途：轻量独立的 Web 设置同步服务器（历史兼容保留，现已合入 loader.js）。

10. 【油猴单文件脚本】 agy-enhancer.user.js
    - 用途：已编译打包好的单文件用户脚本（Userscript）。
    - 适用场景：如果使用浏览器网页端运行 Antigravity，可直接将此文件拖入 Tampermonkey、
      Violentmonkey 等浏览器油猴插件中运行。

11. 【脚本构建工具】 build-userscript.js
    - 用途：开发者工具。用于将 src/agy-enhancer.js 源码自动打包构建为单文件的
      agy-enhancer.user.js 用户脚本。

12. 【默认配置模板】 agy-enhancer-config.json
    - 用途：增强器各项开关的初始预设配置文件（JSON 格式）。


--------------------------------------------------------------------------------
四、 常见疑问与排查技巧
--------------------------------------------------------------------------------

Q1：打开 settings.html 为什么右上角显示红色“服务未连接”？
A1：说明后台守护进程未运行。请双击根目录的 install.bat 或 scripts/start-service-silent.vbs
    重新启动服务，刷新页面后即可变为绿色（● 服务已连接）。

Q2：为什么运行需要 Node.js？
A2：增强器通过极轻量的 Node.js 进程监听本地 127.0.0.1:37210 端口与防重放热通信，日常
    运行时 CPU 占用为 0%，内存仅占极少（10-20MB），不会对系统造成额外负担。

Q3：杀毒软件出现提示怎么办？
A3：由于脚本包含创建 Windows 开机自启快捷方式（.lnk）和静默运行 VBS，部分杀毒软件
    可能会弹出拦截提示，点击“允许操作”或“添加信任”即可，代码均为开源纯文本透明执行。

Q4：我的个人配置存放在哪里？
A4：保存于 Windows 用户的全局应用数据目录：
    %APPDATA%\antigravity\agy-enhancer-config.json
    卸载或重新安装均不会丢失你的个性化设置。
