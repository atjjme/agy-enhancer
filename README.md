# Antigravity 智能阅读增强器 (`agy-read`)

专门为 **Antigravity 2.0 桌面客户端** 定制的对话滚动与阅读体验增强套件。

---

## 🌟 核心特性

1. **思考过程正常滚动**：模型思考及工具调用期间，页面正常跟随滚动，展示实时进展；
2. **思考结束自动平滑回到顶部**：思考完成开始输出回答正文时，页面自动平滑滚回当前问题与回答顶端，并锁定视口供安心阅读；
3. **输入框上方“向下直达底部”悬浮按钮**：离开底部时自适应浮现，点击平滑直达最新底部；
4. **右上角状态提示**：右上角绿点状态徽标，鼠标移入显示运行状态；
5. **100% 官方原厂零侵入**：完全不破坏客户端文件，零崩溃风险，支持完全静默后台运行。

---

## 🚀 极简使用指南（一劳永逸）

本项目提供完全**免黑框、静默后台自启**的体验：

### 1. 一劳永逸（推荐：开机自启）
双击运行根目录下的：
👉 **`设为开机自启 (一劳永逸).bat`**
- 运行一次后，每次开机它都会在后台静默守护；
- **没有黑框**、**不占桌面**；
- 无论打开、重启还是在 Antigravity 中按 `Ctrl + R` 刷新，增强器都会自动实时就绪！

### 2. 手动随时启动/停止
- **`启动服务 (后台静默无黑框).vbs`**：双击即可在后台隐形启动守护；
- **`停止后台服务.bat`**：双击即可完全退出后台守护服务。

## 🎨 手动调节按钮高度
用记事本打开 [`src/agy-enhancer.js`](file:///E:/Prejects/agy-read/src/agy-enhancer.js)：
修改开头的 `BUTTON_OFFSET_ABOVE_INPUT` 数值（如 `32`、`45`、`60`）。
在记事本中按下 `Ctrl + S` 保存，**当前窗口会自动在 0.1 秒内同步新高度**！
