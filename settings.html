增强器全局总开关
全局运行核心控制
增强器全局总开关 核心控制
开启时全面激活各项注入功能；关闭时彻底休眠，客户端不挂载任何事件与监听器，100% 恢复官方原生纯净状态。
系统与自启服务
管理开机静默常驻与任务栏通知区域图标
Windows 开机静默自启动 推荐开启
随 Windows 开机静默在后台启动轻量守护进程，无需手动每次打开软件。
Windows 系统托盘常驻图标 极低开销
在任务栏右下角显示折角跃升图标，提供快速进入设置中心及一键退出。关闭时不常驻任何托盘进程。
对话与阅读体验
长对话快速滚动、记忆恢复与阅读标记
右下角常驻智能翻页双按钮 核心功能
在对话右下角提供向上（↑）/向下（↓）平滑滚动翻阅长对话，双击可直接瞬间直达最新消息。
屏蔽聊天输入框上方官方原生向下按钮 屏蔽原生功能
向上翻看历史消息时，自动屏蔽官方在输入框正上方弹出的遮挡性（↓）小圆钮。
多会话阅读进度记忆与自动回滚 体验优化
在左侧切换不同对话时，自动恢复您上次阅读的历史位置，告别每次切换都滚到底部重新翻找。
智能未读/已读状态精确追踪 默认关闭
真实触底阅读后才将消息标记为已读，避免切换经过被误标已读。关停后可停止定时器节省资源。
AI 回复钉选与画中画速览 (PiP) 高效神器
在 AI 回复卡片上提供钉选按钮，在顶部生成悬浮胶囊与独立可拖拽速览卡片，边看长代码边继续提问。
分支与工作树管理
一键分叉会话、清理失效分支与配置跨分支同步
会话切片分叉与分支创建 (Create fork) 协作利器
允许从任一消息节点一键复制切片并新建对话分支，自动前缀规范化命名，支持并行探索多种解决方案。
分支与工作树列表快捷管理
在顶部工作树下拉面板中显示悬停删除垃圾桶，并提供右键复制名称/路径、在终端/资源管理器打开等菜单。
开分支自动同步本地配置与共享编译缓存
创建新分支时，自动拷贝未纳入 Git 的 .env*、local.properties，并自动配置 Rust / Gradle 共享缓存，秒级构建。
交互与菜单增强
统一右键接管、文本划词与弹窗控制
全局右键功能增强 推荐开启
接管侧边栏项目/会话、聊天内容、代码块与图片的右键操作。关闭后彻底不拦截原生右键。
屏蔽选中文本时的 Quote 浮窗气泡 屏蔽原生功能
划词选择文字时不再弹出官方 Quote (Ctrl+L) 气泡，彻底消除文本选择时的卡顿感（从属于右键菜单开关）。
屏蔽项目右键菜单 Show in File Explorer 屏蔽原生功能
屏蔽官方原生重复的 Show in File Explorer 菜单项，统一使用增强器提供的 Open Project Folder 快捷打开。
屏蔽左侧栏右键原生 Copy 菜单项 屏蔽原生功能
屏蔽左侧栏会话与项目右键菜单中官方原生的 Copy 多级子菜单及复制项，统一纯净交互。
